🚀 Robot Banao BD - Deployment Guide

Step 1: Test Locally (Optional)

First, make sure you have Node.js installed. Then run:

npm install
npm run dev

Open http://localhost:8888 in your browser.

Step 2: Create GitHub Repository

  1. Go to GitHub and create a new repository
  2. Name it something like Robot Banao-bd
  3. Keep it public (required for free Netlify hosting)
  4. Don't initialize with README (we already have one)

Step 3: Push Code to GitHub

Open PowerShell in your project folder and run:

git init
git add .
git commit -m "Initial commit - Robot Banao BD website"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO.git
git push -u origin main

⚠️ Replace YOUR_USERNAME and YOUR_REPO with your actual GitHub username and repository name!

Step 4: Deploy to Netlify

  1. Go to Netlify and sign up/login (use GitHub)
  2. Click "Add new site" → "Import an existing project"
  3. Choose "Deploy with GitHub"
  4. Select your repository
  5. Netlify will auto-detect settings from netlify.toml
  6. Click "Deploy site"

✅ Your site will be live in 1-2 minutes!

Step 5: Customize Your Site

  1. Click "Site settings" in Netlify dashboard
  2. Go to "Domain management"
  3. Click "Options" → "Edit site name"
  4. Choose a name like Robot Banao-bd
  5. Your site will be at: Robot Banao-bd.netlify.app

Step 6: Update Contact Information

Before going live, update these in index.html:

  • Phone number: Search for +880 1XXX-XXXXXX
  • Email: Search for info@Robot Banaobd.com

Then commit and push changes:

git add .
git commit -m "Update contact information"
git push

✅ Netlify will automatically redeploy!

Optional: Custom Domain

To use your own domain (e.g., Robot Banaobd.com):

  1. Buy a domain from Namecheap, GoDaddy, etc.
  2. In Netlify: Site settings → Domain management → Add custom domain
  3. Follow the DNS configuration instructions

Optional: Email Notifications

To receive emails when someone places an order:

  1. Sign up for SendGrid (free tier: 100 emails/day)
  2. Get your API key
  3. In Netlify: Site settings → Environment variables
  4. Add: SENDGRID_API_KEY = your_api_key
  5. Update the function code (see README.md)

📊 View Orders

To see orders placed on your site:

  1. Go to Netlify dashboard
  2. Click on "Functions"
  3. Click on "submit-order"
  4. View the logs to see all orders

💡 For production, integrate with a database (Airtable, Google Sheets, Firebase)

🎉 You're Done!

Your robotics shop is now live and ready to accept orders!

Share your site link with customers and start selling! 🤖
